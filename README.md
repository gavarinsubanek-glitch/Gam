# BOO! Party Night

เว็บเดโมเช็กอินงานฮาโลวีน ใช้ HTML, CSS และ JavaScript ในไฟล์ `demo.html`

## เปิดดูเดโม

เปิด `demo.html` ในเบราว์เซอร์ได้โดยตรง หรือใช้เซิร์ฟเวอร์ในเครื่อง:

```sh
python -m http.server 8765 --bind 127.0.0.1
```

จากนั้นเปิด http://127.0.0.1:8765/demo.html

การเปิดกล้องต้องอาศัย localhost หรือ HTTPS และสิทธิ์จากผู้ใช้

## สถานะของไฟล์ต้นฉบับ

- โหมดทดลองทำงานอัตโนมัติ เพราะ `API_URL` ยังเป็นค่าตัวอย่าง `XXXXXXXX` จึงยังไม่บันทึกข้อมูลจริงลง Google Sheet
- ชื่อและรหัสที่กรอกอัตโนมัติเป็นค่าที่มีอยู่ในไฟล์ต้นฉบับ ควรตรวจสอบก่อนเผยแพร่สู่สาธารณะ
- ZIP ต้นฉบับมีเพียง `demo.html` ไม่มีโฟลเดอร์ `frames/` โค้ดมีกรอบสำรองสำหรับโหมดทดลอง
- ฟอนต์โหลดจาก Google Fonts และต้องใช้อินเทอร์เน็ต
- ยังไม่ได้ตั้งค่าระบบสำหรับใช้งานจริง

## ทำงานร่วมกัน

ใช้ Private repository และเชิญเฉพาะผู้ร่วมงานที่เจ้าของระบุ เริ่มงานแต่ละครั้งโดยดึง `main` ล่าสุด แล้วแยก branch สำหรับงานของตน เช่น `fix/check-in-layout` หรือ `feature/card-design`

```sh
git switch main
git pull
git switch -c fix/check-in-layout
```

หลังแก้ไข ให้ตรวจหน้าเว็บ ส่ง branch ขึ้น GitHub แล้วเปิด Pull Request เพื่อให้ตรวจสอบก่อนรวมเข้า `main` อ่านรายละเอียดใน `CONTRIBUTING.md`

ขณะนี้โค้ดอยู่ในไฟล์เดียว ควรตกลงส่วนที่จะปรับก่อนเริ่มทำพร้อมกัน
